# Boolean Cofactor Layers a = 1, 2, 3, 6

**Status:** exact deterministic criteria

The untwisted cofactor-layer criterion is

\[
\exists q\mid n+4a:
\qquad
q\equiv-1\pmod{4a}.
\]

For the special values

\[
a\in\{1,2,3,6\},
\]

the unit group modulo `4a` has exponent `2`. Hence the set of residues represented by divisors is exactly the subgroup generated by the prime-factor residue classes, and failure can be described by finite `F_2` linear algebra.

Throughout this note `n` is in the true classical core, so

\[
n\equiv1\pmod{24}.
\]

## Layer a = 1

We ask whether

\[
n+4
\]

has a divisor

\[
q\equiv3\pmod4.
\]

Because `n+4 == 1 (mod 4)`, this is equivalent to the classical shift criterion.

Failure is exactly

\[
\boxed{
\text{every odd prime factor of }n+4\text{ is }1\pmod4.
}
\]

This is the classical first rigidity layer.

## Layer a = 2

Now the target is

\[
q\equiv7\pmod8,
\qquad q\mid n+8.
\]

Since `n == 1 (mod 24)`,

\[
n+8\equiv9\pmod{24},
\]

so `3 | n+8`. The prime `3` contributes the residue `3 mod 8`.

The unit group modulo `8` is

\[
\{1,3,5,7\}\cong C_2\times C_2,
\]

with

\[
3\cdot5\equiv7\pmod8.
\]

Therefore a divisor `7 mod 8` exists iff either

- a prime factor is already `7 mod 8`, or
- some prime factor is `5 mod 8`, because the fixed factor `3` can be multiplied by it.

Thus failure is exactly

\[
\boxed{
\forall p\mid n+8,\qquad p\equiv1\text{ or }3\pmod8.
}
\]

Equivalently, the quotient `(n+8)/3` has no prime divisor `5` or `7 mod 8`.

## Layer a = 3

The target is

\[
q\equiv11\pmod{12},
\qquad q\mid n+12.
\]

Since

\[
n+12\equiv13\pmod{24},
\]

it is coprime to `6`, so every prime factor lies in

\[
(\mathbb Z/12\mathbb Z)^\times
=
\{1,5,7,11\}
\cong C_2\times C_2.
\]

A divisor `11 mod 12` exists if

- some prime factor is `11 mod 12`, or
- there is at least one `5 mod 12` factor and at least one `7 mod 12` factor, since `5*7 == 11 mod 12`.

Hence failure is exactly the union of the two subgroup cases

\[
\boxed{
R_{12}(n+12)\subseteq\{1,5\}
\quad\text{or}\quad
R_{12}(n+12)\subseteq\{1,7\}.
}
\]

## Layer a = 6

The target is

\[
q\equiv23\pmod{24},
\qquad q\mid n+24.
\]

The unit group

\[
(\mathbb Z/24\mathbb Z)^\times
=
\{1,5,7,11,13,17,19,23\}
\cong C_2^3.
\]

Associate each prime-factor residue with its vector in `F_2^3`. A divisor congruent to `23 mod 24` exists iff the target vector for `23` lies in the span of the vectors contributed by the prime factors.

Therefore failure is exactly

\[
\boxed{
23\notin\langle R_{24}(n+24)\rangle.
}
\]

Equivalently, all prime-factor residue vectors lie in some codimension-one subgroup (a character kernel) that does not contain `23`.

## Finite-data effect through 10^8

On the **26,399** corrected residual primes through `10^8`:

- `a=2` alone solves **11,570**;
- `a=2 or 3` solves **16,321**;
- `a=2,3, or 6` solves **19,010**, about **72.0%**;
- `a=2,3,4,5,6` solves **23,561**, about **89.3%**.

These counts are finite evidence only. The criteria above are exact theorems.

## Analytic interpretation

Each Boolean-layer failure is a half-group / character-kernel restriction on the prime factors of a different shifted integer `n+4a`. Because distinct shifts have only finitely many collision primes, these layers are natural inputs to a multi-linear-form sieve.

They do not by themselves prove finiteness, but they expose the first levels of the rigidity cascade in completely explicit residue terms.
