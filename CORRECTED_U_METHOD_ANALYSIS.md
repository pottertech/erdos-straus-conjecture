## 1. Exact criterion now used

For `u = 4x - n`, the identity

\[
(uy-nx)(uz-nx)=n^2x^2
\]

shows that a candidate `u` succeeds when there is an actual complementary divisor pair

\[
d_1d_2=n^2x^2
\]

with

\[
d_1\equiv d_2\equiv -nx\pmod u.
\]

The verifier now constructs the corresponding

\[
y=(d_1+nx)/u,\qquad z=(d_2+nx)/u
\]

and checks the original equation by exact integer arithmetic.

The previous shortcut using the three residues `{-x*n^j : j=0,1,2}` is not used as a proof-equivalent criterion.

## 5. Immediate theorem target

The corrected computation suggests studying the divisor product set directly.

Let

\[
D=n^2x^2,
\qquad t=-nx\pmod u.
\]

The exact problem is to prove that, for some small `u ≡ 3 (mod 4)`, the divisor set of `D` contains an element `d` such that

\[
d\equiv t\pmod u
\]

and its complementary divisor simultaneously satisfies

\[
D/d\equiv t\pmod u.
\]

When `gcd(t,u)=1`, the second condition is equivalent to

\[
D\equiv t^2\pmod u,
\]

which already holds identically because `D=n^2x^2` and `t=-nx`. Therefore, for units modulo `u`, the problem reduces to finding one divisor

\[
\boxed{d\mid n^2x^2,\qquad d\equiv -nx\pmod u.}
\]

This is a bounded product-set problem in `(Z/uZ)^*`, generated by the residues of prime factors of `n` and `x`, with exponents bounded by those in `n^2x^2`.

That formulation is cleaner than the previous probabilistic three-target argument and should be the primary route for the next proof attempt.
