# Exact Residue Cascade After the u-Method Correction

**Date:** 2026-08-28

This note replaces the old three-target residue cascade with the exact divisor criterion.

## 1. Correct reduced criterion

Let \(u\equiv3\pmod4\), \(x=(n+u)/4\), and \(D=(nx)^2\).  The u-method requires a divisor \(d\mid D\) such that

\[
d\equiv -nx\pmod u.
\]

If \(\gcd(nx,u)=1\), then the complementary divisor automatically has the same residue because

\[
D=(nx)^2\equiv(-nx)^2\pmod u.
\]

For prime \(n\) and prime \(u\nmid n\), write \(x=\prod p_i^{e_i}\).  Every divisor of \(D\) is

\[
d=n^\alpha\prod p_i^{\beta_i},\qquad \alpha\in\{0,1,2\},\quad 0\le\beta_i\le2e_i.
\]

After dividing by \(nx\), the exact centered criterion is

\[
n^a\prod p_i^{b_i}\equiv-1\pmod u,
\]

where

\[
a\in\{-1,0,1\},\qquad -e_i\le b_i\le e_i.
\]

Equivalently, if one insists on reducing to divisors \(e\mid x^2\), the three exact targets are

\[
\boxed{-x,\;-xn,\;-xn^{-1}}\pmod u,
\]

not \(\{-x,-xn,-xn^2\}\).  The old third target agrees with the correct one only when \(n^3\equiv1\pmod u\).

## 2. Full diagnosis through 10^7

Comparing the old shortcut to the exact verifier for all 48,711 prime hard cases through \(10^7\):

- exact verifier failures with \(u\le300\): **0**;
- cases whose first-working \(u\) changes: **405**;
- all **405** old false first hits occur at the old **j=2** target;
- all **405** satisfy \(n^3\not\equiv1\pmod{u_{\rm old}}\);
- changed cases occur only for \(n\equiv1\) or \(49\pmod{120}\).

Thus the correction is completely localized: the old j=0 and j=1 reductions are valid, while the old j=2 reduction is the sole source of the discrepancy.

## 3. Exact deterministic coverage modulo 120

The prime hard-case candidate classes modulo 120 are

\[
1,13,37,49,61,73,97,109.
\]

Using only the guaranteed divisors generated by \(n\), \(x\), and factors among \(2,3,5\) whose divisibility of \(x=(n+u)/4\) is forced by the class, the corrected criterion gives a universal small-u proof for six of the eight classes.

The only base classes for which this guaranteed-factor analysis has no universal hit are

\[
\boxed{n\equiv1,49\pmod{120}}.
\]

This exactly matches the two classes in which the corrected and old first-working parameters differ.

## 4. Two deterministic QNR lemmas

### Lemma A: u=7

Suppose \(n\equiv1\) or \(49\pmod{120}\).  Then \(n\equiv1\pmod8\), hence

\[
x_7=\frac{n+7}{4}
\]

is even.  Therefore the guaranteed divisor set includes powers of the factor 2.

An exhaustive calculation in \((\mathbb Z/7\mathbb Z)^\times\), using only divisors

\[
n^a x_7^b2^c,\qquad a,b,c\in\{0,1,2\},
\]

shows that the exact target \(-nx_7\) fails precisely for

\[
\{1,2,4\}=\mathrm{QR}_7.
\]

Hence

\[
\boxed{\left(\frac n7\right)=-1\quad\Longrightarrow\quad u=7\text{ succeeds}.}
\]

### Lemma B: u=11

For every hard-case candidate \(n\equiv1\pmod{12}\),

\[
x_{11}=\frac{n+11}{4}
\]

is divisible by 3.  Using guaranteed divisors

\[
n^a x_{11}^b3^c,\qquad a,b,c\in\{0,1,2\},
\]

the exact target fails precisely for

\[
\{1,3,4,5,9\}=\mathrm{QR}_{11}.
\]

Therefore

\[
\boxed{\left(\frac n{11}\right)=-1\quad\Longrightarrow\quad u=11\text{ succeeds}.}
\]

### Consequence

Any prime in the two residual classes that is not already solved by these two exact routes must satisfy

\[
\boxed{\left(\frac n7\right)=\left(\frac n{11}\right)=+1.}
\]

This is a deterministic restriction, not a density heuristic.

## 5. Refinement modulo 120120

Refine the two residual base classes modulo

\[
M=\operatorname{lcm}(120,28,44,52)=120120,
\]

so that divisibility of \(x\) by \(2,3,5,7,11,13\) can be decided whenever it is forced by the residue class.

Among residue classes coprime to \(2\cdot3\cdot5\cdot7\cdot11\cdot13\) and lying above \(1\) or \(49\pmod{120}\):

- admissible classes: **1,440**;
- deterministically covered using prime \(u\equiv3\pmod4\), \(u\le127\): **1,214**;
- remaining: **226**.

Every one of the 226 remaining classes is a quadratic residue modulo both 7 and 11.  Of them, 180 are also quadratic residues modulo 13 and 46 are non-residues modulo 13.

The 180 classes that are QR modulo 7, 11, and 13 are exactly the unit-square classes modulo 120120.

## 6. Interpretation

The remaining obstruction is increasingly concentrated in simultaneous quadratic-residue subgroups.  This provides a cleaner path than the discarded independence argument:

1. use exact small-u divisor routes to eliminate QNR classes;
2. refine the modulus by forced factors of \((n+u)/4\);
3. identify the surviving subgroup intersection;
4. prove that another fixed u or forced factor breaks that intersection.

The central open target is now a deterministic subgroup/product-set statement for primes satisfying

\[
n\equiv1\text{ or }49\pmod{120},\qquad
\left(\frac n7\right)=\left(\frac n{11}\right)=1.
\]
