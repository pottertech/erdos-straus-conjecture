# Squarefree-Semiprime Mixed Rescue Core

**Status:** exact reduction plus finite census.  The underlying square-completed shadow geometry and the fact that `u^2,v^2` are the only mixed square divisors are aligned with the 2026 FCF/CENTL program; no novelty claim is made for that prior structure.

Let

\[
A=uv
\]

with distinct primes `u<v`, and put

\[
m_A=4uv-1.
\]

For the square-completed Type-II layer, the divisors of `A^2` are

\[
1,u,v,u^2,uv,v^2,u^2v,uv^2,u^2v^2.
\]

The López boundary orthants contain all except

\[
\boxed{u^2,\ v^2}.
\]

Thus the genuinely square-only part of a squarefree-semiprime layer is exactly the pair

\[
\boxed{-4u^2,\ -4v^2\pmod{m_A}},
\]

or equivalently

\[
\boxed{-u/v,\ -v/u\pmod{m_A}}.
\]

## Exact ancestry test

Let `B<A` satisfy

\[
m_B=4B-1\mid m_A.
\]

Then

\[
A\equiv B\pmod{m_B}.
\]

Define

\[
Q_B=\{E\pmod{m_B}:E\mid B^2\}.
\]

### Theorem

The mixed direction `u^2` is inherited from depth `B` iff

\[
\boxed{u^2\pmod{m_B}\in Q_B.}
\]

When this happens, `v^2` is inherited automatically.

### Proof of pairing

If `u^2 == E (mod m_B)` for some `E|B^2`, then

\[
v^2=\frac{A^2}{u^2}
\equiv
\frac{B^2}{E}
\pmod{m_B}.
\]

Because `B^2/E` is again a divisor of `B^2`, the second mixed direction is also in `Q_B`.  Symmetry gives the converse.

Therefore the squarefree-semiprime mixed rescue is an indivisible two-direction object along every divisor-modulus ancestry edge: **both directions are shadowed or neither is**.

The script `semiprime_mixed_rescue_analyzer.py` implements this test without searching primes `p`.

## Bottom universal square-saturation filters

Two tiny ancestors are especially strong because their divisor-square sets exhaust every nonzero square class of their moduli.

### B = 1, modulus 3

\[
Q_1=\{1\},
\]

the complete nonzero square set modulo `3`.  Hence

\[
\boxed{A\equiv1\pmod3\Longrightarrow B=1\text{ shadows the mixed pair}.}
\]

### B = 2, modulus 7

\[
Q_2=\{1,2,4\},
\]

the complete nonzero quadratic-residue set modulo `7`.  Hence

\[
\boxed{A\equiv2\pmod7\Longrightarrow B=2\text{ shadows the mixed pair}.}
\]

Together these remove exactly `3/7` of raw index residue classes modulo `21`.

The previously noted condition

\[
A\equiv4\pmod{15}
\]

also yields shadowing through `B=4`, but it is **not an additional filter** here because it already implies `A==1 (mod 3)`, so `B=1` has shadowed the pair first.  This is consistent with the finite census: `B=4` never appears as the minimum inheriting ancestor.

## Partial-square ancestors beyond 3 and 7

Further ancestors need not contain every square class to be effective.

For `B=3`, the ancestor modulus is `11` and

\[
Q_3=\{1,3,9\}\pmod{11},
\]

which captures three of the five nonzero quadratic-residue classes.

For `B=6`, modulus `23`,

\[
Q_6=\{1,2,3,4,6,9,12,13,18\},
\]

capturing nine of the eleven nonzero quadratic-residue classes.

Thus the residual semiprime core is generated by repeated **partial square-class avoidance**: for every proper ancestry modulus, the factor square `u^2` must avoid the finite ancestor divisor-square set `Q_B`.

## Research consequence

The correct semiprime composite-rescue object is no longer the full divisor lattice.  It is the residual set of pairs

\[
(A=uv,\ -u/v,\ -v/u)
\]

for which no smaller ancestry modulus accepts the square class of `u`.

Equivalently, if `d=4B-1` runs over proper divisors of `4uv-1` with `d==3 (mod 4)`, a primitive semiprime mixed layer must satisfy

\[
\boxed{u^2\notin Q_{(d+1)/4}\pmod d}
\]

for every such `d`.

The next useful theorem target is therefore:

> Prove that a squarefree semiprime `uv` cannot satisfy all of these square-class avoidance conditions indefinitely, or show that simultaneous avoidance forces a controlled successor Type-II layer.

This reframes the composite rescue wall as a finite family of local square-class exclusions attached to the factorization of `4uv-1`.

## Claim boundary

This note does not prove that every prime denominator is rescued by a squarefree-semiprime layer.  It only gives an exact reduction and demonstrates that the truly new semiprime part is much smaller than the raw square-divisor search suggests.
