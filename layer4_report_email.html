Key structural finding — the Jacobi invariant

When (A/n) = 1 (direct route fails), the Jacobi symbol (n / m_A) = (m_A / A) = 1 always holds. This is a zero-information invariant: it cannot distinguish m-route success (2+ QNR factors) from failure (0 QNR factors). The m-route success is determined at the factorization level, not the symbol level. This is why Layer 4 cannot be proven by algebraic identities alone.

5. Outlier Analysis: n = 8,803,369

This prime requires A = 107, the largest A needed for any n ≤ 10M.

Two failure modes

  • No-QNR failures (A ≤ 31, 35, 39, 47, 51, 55, 63, 71, 75, 87, 91, 95, 99): n is QR mod A, so no QNR generator exists. A is simply inapplicable.
  • Gap failures (A = 43, 59, 67, 79, 83, 103): n is QNR mod A (h even, −1 ∈ H(A)), but the centered sumset Σ_A(N) cannot reach h/2. All gaps occur at odd h/2 values — consistent with the parity obstruction (Theorem 10).

At A = 107, the direct route finally works. The centered representation uses 3 signed terms: δ₃ = −2, δ₄₃ = −1, δ₄₇ = −1.

The Burgess-style route in Proposition 8 suggests a bound of the form A = O(n1/(4√e)+ε) ≈ O(n0.1515+ε) under the stated analytic assumptions. The observed A = 107 is far below this scale for n ≈ 8.8M.
