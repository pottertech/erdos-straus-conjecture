# Explicit Jacobi Ancestry Basis Certificates

**Status:** unconditional constructive corollary of the first-occurrence span theorem.

For a depth `A`, write

\[
m_A=4A-1
\]

and let

\[
S(A)=\{r:\ r\text{ prime and }\operatorname{ord}_r(m_A)\text{ is odd}\}.
\]

Split

\[
S_3(A)=\{r\in S(A):r\equiv3\pmod4\},
\qquad
S_1(A)=\{r\in S(A):r\equiv1\pmod4\}.
\]

Let

\[
v_A=(\operatorname{ord}_r(m_A)\bmod2)_r
\]

be the parity vector representing the Jacobi character

\[
\chi_A(n)=\left(\frac{n}{m_A}\right).
\]

Assume the target layer is **not** one of the two Jacobi-new cases:

1. `m_A` prime;
2. `m_A=3q` with `q == 1 (mod 4)` prime.

Then all depths appearing below are strictly smaller than `A`.

## Theorem: canonical ancestry certificate

Define

\[
B_r=\frac{r+1}{4}
\qquad(r\in S_3(A)),
\]

and

\[
C_r=\frac{3r+1}{4}
\qquad(r\in S_1(A)).
\]

Then

\[
\boxed{
 v_A
 =
 \sum_{r\in S_3(A)}v_{B_r}
 +
 \sum_{r\in S_1(A)}v_{C_r}
 +
 (|S_1(A)|\bmod2)v_1.
}
\]

Equivalently, for every integer `n` coprime to all of the displayed moduli,

\[
\boxed{
\chi_A(n)
=
\prod_{r\in S_3(A)}\chi_{B_r}(n)
\prod_{r\in S_1(A)}\chi_{C_r}(n)
\chi_1(n)^{|S_1(A)|\bmod2}.
}
\]

This gives an explicit certificate of Jacobi dependence on earlier backbone layers.

### Proof

For `r == 3 (mod 4)`,

\[
4B_r-1=r,
\]

so

\[
v_{B_r}=e_r.
\]

For `r == 1 (mod 4)`,

\[
4C_r-1=3r,
\]

so

\[
v_{C_r}=e_3+e_r.
\]

Also

\[
v_1=e_3
\]

because `4*1-1=3`.

Therefore the right-hand side is

\[
\sum_{r\in S_3(A)}e_r
+
\sum_{r\in S_1(A)}(e_3+e_r)
+
(|S_1(A)|\bmod2)e_3.
\]

The `e_3` contributions from the second and third terms cancel, leaving

\[
\sum_{r\in S_3(A)}e_r+
\sum_{r\in S_1(A)}e_r
=v_A.
\]

Strict earlierness follows from the first-occurrence argument. If `B_r=A` for an `r == 3 mod 4`, then `m_A=r` is prime. If `C_r=A` for an `r == 1 mod 4`, then `m_A=3r`; for a prime `r` this is exactly the composite Jacobi-new case. Both are excluded by hypothesis.

## Corollary: short dependence certificate

The target Jacobi character can be certified dependent using at most

\[
\boxed{
\omega(\operatorname{rad}(m_A))+1
}
\]

earlier character factors, and usually no more than

\[
\omega(\operatorname{rad}(m_A)).
\]

Repeated occurrences of depth `1` cancel in `F_2`, so only one optional `v_1` term is needed.

## Corollary: prime/3q layers generate the entire ancestry spectrum

Every Jacobi character in the sequence

\[
\chi_A(n)=\left(\frac{n}{4A-1}\right)
\]

is generated by the characters arising from the two first-occurrence classes:

1. prime target moduli `q == 3 (mod 4)`;
2. composite target moduli `3q` with `q == 1 (mod 4)` prime.

Thus the prime and `3q` backbones are not merely the layers at which rank grows. They give an explicit sparse generating system for every later Jacobi character.

## Interpretation for exact-depth avoidance

If a proposed exact-depth construction imposes Jacobi sign `+1` on all earlier backbone characters in this certificate, then the target Jacobi sign is automatically `+1` as well. Since every divisor-square target trap at depth `A` has target Jacobi sign `-1`, the certificate gives a short explicit obstruction to any globally Jacobi-safe exact-depth construction at that layer.

This turns the abstract span contradiction into a concrete finite ancestry certificate attached directly to the prime factorization of `4A-1`.
